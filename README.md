# Montaj plugin

Montaj is a video editor your AI drives: projects, cuts, captions, renders.

The plugin needs the Montaj app. Get it at [montaj.ag](https://montaj.ag) and open it once.

## Claude Code

```
/plugin marketplace add By-Crux/montaj-plugins
/plugin install montaj@montaj
```

## Codex

```
codex plugin marketplace add By-Crux/montaj-plugins
codex plugin add montaj@montaj
```

## No plugins?

If your AI can't install plugins, open Montaj, go to Connect AI, pick Another AI and copy the MCP config into your AI's MCP settings.
